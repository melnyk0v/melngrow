# melngrow

Сайт meln.grow (melngrow.com). GitHub Pages публікує папку `docs/` з гілки `main`.

Оновлення: розпакуй новий `meln-grow-site.zip` і перетягни папку `docs` цілком у **Add file → Upload files** → **Commit changes**. Файл `docs/CNAME` (його створює GitHub, коли вписуєш свій домен) не видаляй.
