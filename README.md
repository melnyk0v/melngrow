# melngrow

Сайт meln.grow (melngrow.com). GitHub Pages публікує папку `docs/` з гілки `main`.

З 13.11.2026 тут новий дизайн: одна сторінка українською, головна послуга «Налаштування реклами в Meta та Google».
Попередній дизайн (чотири мови) лишився в історії репозиторію, коміт `0e58986`.

Оновлення: розпакуй новий `meln-grow-site-v2.zip` і перетягни папку `docs` цілком у **Add file → Upload files** → **Commit changes**. Файл `docs/CNAME` (його створює GitHub, коли вписуєш свій домен) не видаляй.
